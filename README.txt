threehyphens 創作サイト
========================

このリポジトリは、threehyphensが運営する個人創作サイトの公開用データを
管理するためのものです。オリジナルの小説・漫画・イラストと、サイトの
表示に必要なHTML・CSS・画像ファイルを収録しています。

作品・画像等の利用条件は、公開サイト内の「About」をご確認ください。
このREADMEおよびリポジトリの公開は、同ページに記載された条件以外の利用を
追加で許可するものではありません。

内容
----
index.html                         トップページ
styles.css                         デザイン設定
assets/images/threehyphens-cat.png 猫のイラスト
works/moto-yusha/index.html         小説の作品トップ・目次
works/moto-yusha/episodes/          第1話～第10話の本文ページ
works/crowbar-nurse/index.html      「バールナース」の作品トップ・章別目次
works/crowbar-nurse/episodes/       公開済み全131話の本文ページ
works/crowbar-nurse/illustrations/  全170枚・全15ページのイラストコーナー
works/crowbar-nurse-short-stories/index.html  「バールナース番外短編集」の作品トップ・目次
works/crowbar-nurse-short-stories/episodes/   全12話の本文ページ
works/oshimai-nekochan/index.html   「オシマイのネコチャン」の作品トップ
works/oshimai-nekochan/comics/      全25枚・全3ページの漫画コーナー
works/father-essay/index.html        「父上エッセイ」の作品トップ・目次
works/father-essay/episodes/         全11話の本文ページ
works/okan-comic/index.html          「オカン漫画」の作品トップ
works/okan-comic/comics/             全16枚・全4ページの漫画コーナー

「元勇者、わが子と国道沿いを楽しむ」は全10話を掲載済みです。
「バールナース」は公開済みの全131話を、7章に分けて掲載しています。
同作品のイラスト170枚を、9～20枚ずつ15ページに分けて掲載しています。
「バールナース番外短編集」は公開済み11話に、バックアップ内で下書きだった
「それは本当に、熱中症ではないですね……。」をEP.12として加えた全12話を掲載しています。
「オシマイのネコチャン」は漫画25枚を、3ページに分けて掲載しています。
「父上エッセイ」は全11話を掲載しています。
「オカン漫画」は漫画16枚を、4枚ずつ4ページに分けて掲載しています。
「Activity / 活動紹介」には、作品・SNS・ブログ・ショップ・依頼窓口をまとめています。
掲載画像は、ウェブ閲覧向けにサイズと容量を調整しています。
「バールナース」はバックアップ内の下書き1話を掲載していません。

パソコン上で確認する場合
------------------------
index.html をブラウザーで開いてください。
